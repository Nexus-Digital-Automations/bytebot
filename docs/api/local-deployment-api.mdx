# Local Deployment API Documentation

## Overview

This documentation covers the Bytebot API endpoints specifically configured for local deployment scenarios. All endpoints are designed to work with localhost networking, local authentication, and file-based storage—maintaining complete independence from cloud services.

## Base Configuration

### Local API Base URL
```
# Development
http://localhost:3000/api/v1

# Production with SSL
https://localhost:3000/api/v1

# Local network access
http://192.168.1.100:3000/api/v1
```

### Local Authentication
- **JWT Tokens**: Signed locally with RSA keys stored in `secrets/jwt/`
- **Session Storage**: File-based sessions in `data/sessions/`
- **No External OAuth**: Self-contained authentication system

## Core API Endpoints

### Authentication Endpoints

**Local Configuration:**
- User data stored in local database (SQLite/PostgreSQL)
- Password hashing performed locally
- No external validation services

### Local API Client Examples

#### JavaScript/Node.js Client
```javascript
class LocalBytebotClient {
  constructor(baseUrl = 'http://localhost:3000/api/v1') {
    this.baseUrl = baseUrl;
    this.token = null;
  }

  async login(email, password) {
    const response = await fetch(`${this.baseUrl}/auth/login`, {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ email, password })
    });

    const data = await response.json();
    if (data.success) {
      this.token = data.data.tokens.accessToken;
    }
    return data;
  }

  async uploadFile(filePath, localPath) {
    const formData = new FormData();
    formData.append('file', fs.createReadStream(filePath));
    formData.append('localPath', localPath);

    const response = await fetch(`${this.baseUrl}/files/upload`, {
      method: 'POST',
      headers: { 'Authorization': `Bearer ${this.token}` },
      body: formData
    });

    return response.json();
  }

  async createLocalTask(title, config) {
    const response = await fetch(`${this.baseUrl}/tasks`, {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${this.token}`
      },
      body: JSON.stringify({ title, ...config })
    });

    return response.json();
  }
}
```

#### Python Client
```python
import requests
import json
from pathlib import Path

class LocalBytebotClient:
    def __init__(self, base_url="http://localhost:3000/api/v1"):
        self.base_url = base_url
        self.token = None

    def login(self, email, password):
        response = requests.post(
            f"{self.base_url}/auth/login",
            json={"email": email, "password": password}
        )

        data = response.json()
        if data.get("success"):
            self.token = data["data"]["tokens"]["accessToken"]
        return data

    def upload_file(self, file_path, local_path=None):
        files = {"file": open(file_path, "rb")}
        data = {"localPath": local_path} if local_path else {}

        response = requests.post(
            f"{self.base_url}/files/upload",
            files=files,
            data=data,
            headers={"Authorization": f"Bearer {self.token}"}
        )

        return response.json()

    def get_local_health(self):
        response = requests.get(f"{self.base_url}/health")
        return response.json()
```

## Local Security Considerations

### API Security Features
- **Local JWT Validation**: Tokens verified with local RSA keys
- **File System Access Control**: Restricted to configured local paths
- **Input Validation**: All inputs sanitized locally
- **Rate Limiting**: Configured for local deployment scenarios
- **Audit Logging**: All API calls logged to local files

### Local Network Security
- **Localhost Binding**: Services bound to local interfaces only
- **SSL/TLS**: Local certificate management
- **Firewall Rules**: Restrict external access
- **CORS Configuration**: Configured for local origins

This API documentation ensures that all Bytebot functionality is accessible through well-defined endpoints while maintaining complete local operation and security.
